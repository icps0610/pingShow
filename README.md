## 功能特點

1. **即時監控**：依設定的時間間隔自動更新各監控目標的 Ping 延遲與連線狀態。
2. **動態擴充**：透過網頁設定面板或編輯 `target.json` 新增或刪除 IP，變更會即時生效，無需重啟程式。
3. **三種檢視模式**：
   - **即時監控 (LIVE)**：依設定間隔持續更新，並顯示最新 60 筆延遲與斷線狀態記錄。
   - **歷史回放**：查詢過去任意整點小時的歷史數據，支援「原始數據」、「1 分鐘平均」與「10 分鐘平均」三種聚合方式。
   - **趨勢檢視**：提供「日平均」與「月平均」長期趨勢圖，天數或月份範圍可於設定中調整。
4. **自適應版面**：
   - **電腦版**：根據監控目標數量自動排版（1 個目標為全螢幕，2 個為上下雙欄，3 個以上為雙列多行網格）。
   - **手機版**：自動切換為垂直單欄，支援左右滑動切換歷史時段。

## 🚀 使用說明

### 1. 設定 `target.json`
程式第一次執行後，會自動在根目錄產生 `target.json` 檔案。你可以直接編輯此檔案，或透過網頁設定面板進行修改：

| 參數 | 說明 | 預設值 |
|---|---|---|
| `port` | 網頁服務連接埠 | `80` |
| `interval` | Ping 間隔秒數 | `1` |
| `ymax` | 圖表 Y 軸最大值 (ms) | `50` |
| `day_range` | 日平均顯示天數 | `7` |
| `month_range` | 月平均顯示月份數 | `3` |
| `timezone` | 時區（IANA 格式），例如 `"Asia/Taipei"`，留空使用系統時區 | `""` |
| `targets` | 監控目標列表（名稱與 IP） | — |

```json
{
    "port": 80,
    "interval": 1,
    "ymax": 50,
    "day_range": 7,
    "month_range": 3,
    "timezone": "Asia/Taipei",
    "targets": [
        { "name": "local",  "ip": "192.168.0.1" },
        { "name": "Taiwan", "ip": "168.95.1.1" },
        { "name": "Google", "ip": "8.8.8.8" }
    ]
}
```

> [!NOTE]
> 修改 `port` 後需重新啟動程式才會生效。其餘設定（包含時區、監控目標列表與圖表範圍）均可在網頁儲存後即時生效，無需重啟程式。

---

### 2. 啟動與訪問

1. **Windows**：在 `pingShow.exe` 上按右鍵選擇「以系統管理員身份執行」（發送 ICMP 封包需要管理員權限）。
2. **Linux / Android (Termux)**：程式會自動使用非 root 的 UDP Ping 模式，直接執行即可。
3. **訪問網頁**：開啟瀏覽器前往 `http://localhost`（若修改了 port 請加上對應的埠號，如 `http://localhost:8010`）。

## 🕹️ 網頁操作與數據說明

### ⚙️ 系統設定
點擊網頁右上角 **「⚙️ 設定」** 按鈕可調整各項參數：
* **監控目標**：可動態新增或刪除監控目標，修改名稱與 IP（儲存時系統會自動過濾重複 IP）。
* **圖表範圍**：可隨時調整 `ymax`、日平均顯示天數 (`day_range`) 與月平均顯示月數 (`month_range`)。
* **時區設定**：若在無安裝時區庫的環境（如手機 Linux App 或部分輕量容器）中時間顯示為 UTC，可手動填入 `"Asia/Taipei"`。程式內建時區資料庫，會自動將日誌儲存與讀取轉換為台北時間。

---

### 💡 數據統計說明 (Stats)
每個圖表上方會顯示該時段的連線統計數據：

| 指標 | 說明 |
|---|---|
| `min` / `max` / `avg` | 該時段最快、最慢與平均延遲（毫秒） |
| `jtr` | Jitter（抖動率），數值越低代表連線越穩定 |
| `p95` | 第 95 百分位數延遲，代表 95% 的延遲時間低於此值 |
| `t/o` | Timeout 次數（斷線/掉包），圖表在斷線點會以留白呈現 |

> [!NOTE]
> - **LIVE 即時模式**：統計數值會在每小時整點自動重置，僅顯示當前這一小時的統計。
> - **歷史回放模式**：顯示所選小時內的全部數據統計。

---

### ⌨️ 按鍵與手勢操作

| 操作 | 電腦 | 手機 |
|---|---|---|
| 查看上一小時 | `A` 鍵 / `←` 方向鍵 | 向右滑動 |
| 查看下一小時 | `D` 鍵 / `→` 方向鍵 | 向左滑動 |
| 切回 LIVE 即時 | 點擊綠色「切回即時」按鈕 | 同左 |

> [!TIP]
> - 在 LIVE 模式下第一次按 `A`（向右滑動），會先停在「當前小時的歷史靜態檢視」，再按一次才開始往前切換。
> - 在歷史模式下按 `D`（向左滑動），當切換時間超過當前時刻時，會自動切回 LIVE 即時模式。
> - **手機滑動防誤觸**：系統僅在水平滑動長度大於垂直滑動長度 1.5 倍以上時才會觸發切換，且會自動忽略在「設定視窗」內部、輸入框、下拉選單與按鈕上的滑動，避免上下捲動頁面或進行設定時發生誤觸。

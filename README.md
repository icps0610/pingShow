## 功能特點

1. **即時監控**：依設定的時間間隔自動更新各監控目標的 Ping 延遲與連線狀態。
2. **動態擴充**：透過網頁設定面板或編輯 `target.json` 新增或刪除 IP，變更會即時生效，無需重啟程式。
3. **五種數據檢視模式**：
   - **即時監控 (LIVE)**：依設定間隔持續更新，並顯示最新 60 筆延遲與斷線狀態記錄。
   - **歷史回放**：查詢過去任意整點小時的歷史數據，支援「1 分鐘」與「原始數據」兩種顯示粒度。
   - **單日每時趨勢**：以 00:00 到 23:00 為時間軸，依目前選擇的指標展示指定日期當天 24 個整點小時的趨勢。
   - **日趨勢**：展示基準日期往前推算過去 N 天的每日趨勢（`day_range`）。
   - **月趨勢**：展示基準日期往前推算過去 N 個月的每月趨勢（`month_range`）。
4. **歷史指標切換**：歷史回放與區間統計可切換 `P95`、`AVG`、`Timeout%`、`Jitter`，預設使用 `P95`，更適合觀察常見尖峰延遲與體感品質。
5. **清楚的工具列分類**：上方控制列依「時間」、「顯示」、「指標」、「工具」、「狀態」分組，避免歷史查詢與系統工具混在一起。
6. **自適應排版與終極防呆佈局**：
   - **電腦版**：根據監控目標數量自動排版（1 個目標為全螢幕，2 個為上下雙欄，3 個以上為雙列多行網格）。
   - **手機版**：自動切換為垂直單欄，控制面板採用全新的三列式剛性 Flexbox 佈局。在不同模式之間切換、隱藏控制項時，面板上的元件會平滑遞補，**保證不會產生任何排版錯位、亂竄或跳動**，並支援左右滑動切換歷史時段。

## 🚀 使用說明

### 1. 設定 `target.json`
程式第一次執行後，會自動在根目錄產生 `target.json` 檔案。你可以直接編輯此檔案，或透過網頁設定面板進行修改：

| 參數 | 說明 | 預設值 |
|---|---|---|
| `port` | 網頁服務連接埠 | `80` |
| `interval` | Ping 間隔秒數 | `1` |
| `ymax` | 圖表 Y 軸最大值 (ms) | `50` |
| `day_range` | 日平均顯示天數 | `7` |
| `month_range` | 月平均顯示月份數 | `3` |
| `timezone` | 時區（IANA 格式），例如 `"Asia/Taipei"`，留空使用系統時區 | `""` |
| `targets` | 監控目標列表（名稱、IP 與是否停用） | — |

```json
{
    "port": 80,
    "interval": 1,
    "ymax": 50,
    "day_range": 7,
    "month_range": 3,
    "timezone": "Asia/Taipei",
    "targets": [
        { "name": "local",  "ip": "192.168.0.1" },
        { "name": "Taiwan", "ip": "168.95.1.1" },
        { "name": "Google", "ip": "8.8.8.8", "disabled": true }
    ]
}
```

> [!NOTE]
> 修改 `port` 後需重新啟動程式才會生效。其餘設定（包含時區、監控目標列表與圖表範圍）均可在網頁儲存後即時生效，無需重啟程式。

---

### 2. 啟動與訪問

1. **Windows**：在 `pingShow.exe` 上按右鍵選擇「以系統管理員身份執行」（發送 ICMP 封包需要管理員權限）。
2. **Linux / Android (Termux)**：程式會自動使用非 root 的 UDP Ping 模式，直接執行即可。
3. **訪問網頁**：開啟瀏覽器前往 `http://localhost`（若修改了 port 請加上對應的埠號，如 `http://localhost:8010`）。

## 🕹️ 網頁操作與數據說明

### ⚙️ 系統設定
點擊網頁右上角 **「⚙️ 設定」** 按鈕可調整各項參數：
* **監控目標管理**：
  - 可動態新增或刪除監控目標，修改名稱與 IP（儲存時系統會自動過濾重複 IP）。
  - **啟用/停用功能**：在列表前方勾選或取消勾選，可隨時暫停指定目標的背景監控並將其圖卡隱藏，完全不會丟失原本的歷史紀錄，重新啟用後立即恢復連線監測。
* **圖表範圍**：可隨時調整 `ymax`、日平均顯示天數 (`day_range`) 與月平均顯示月數 (`month_range`)。
* **時區設定**：若在無安裝時區庫的環境（如手機 Linux App 或部分輕量容器）中時間顯示為 UTC，可手動填入 `"Asia/Taipei"`。程式內建時區資料庫，會自動將日誌儲存與讀取轉換為台北時間。

---

### 💡 數據統計說明 (Stats)
每個圖表上方會顯示該時段的連線統計數據：

| 指標 | 說明 |
|---|---|
| `min` / `max` / `avg` | 該時段最快、最慢與平均延遲（毫秒） |
| `p95` | 第 95 百分位數延遲，代表 95% 的延遲時間低於此值；歷史模式預設使用此指標 |
| `jtr` / `Jitter` | Jitter（抖動），以相鄰有效 Ping 的延遲差計算，數值越低代表連線越穩定 |
| `t/o` | Timeout 次數（斷線/掉包），圖表在斷線點會以留白呈現 |
| `Timeout%` | Timeout 比例，代表指定時間粒度內 timeout 筆數佔全部樣本的百分比 |

> [!NOTE]
> - **LIVE 即時模式**：統計數值會在每小時整點自動重置，僅顯示當前這一小時的統計。
> - **歷史回放模式**：預設顯示 `P95`。可在上方「指標」切換 `P95`、`AVG`、`Timeout%`、`Jitter`。

### ⌨️ 按鍵與手勢操作

| 操作 | 電腦 | 手機 |
|---|---|---|
| 查看上一小時 | `A` 鍵 / `←` 方向鍵 | 向右滑動 |
| 查看下一小時 | `D` 鍵 / `→` 方向鍵 | 向左滑動 |
| 切回 LIVE 即時 | 點擊綠色「切回即時」按鈕 | 同左 |

> [!TIP]
> - 在 LIVE 模式下第一次按 `A`（向右滑動），會先停在「當前小時的歷史靜態檢視」，再按一次才開始往前切換。
> - 在歷史模式下按 `D`（向左滑動），當切換時間超過當前時刻時，會自動切回 LIVE 即時模式。
> - **手機滑動防誤觸**：系統僅在水平滑動長度大於垂直滑動長度 1.5 倍以上時才會觸發切換，且會自動忽略在「設定視窗」內部、輸入框、下拉選單與按鈕上的滑動，避免上下捲動頁面或進行設定時發生误觸。

---

### 📊 歷史與區間數據查詢

1. **小時回放**：在上方控制列選擇「時間」中的日期與時段，點擊「載入」或按 `A`/`D` 鍵切換。
2. **顯示粒度**：在「顯示」中選擇 `1 分鐘` 或 `原始數據`。`1 分鐘` 適合看趨勢，`原始數據` 適合追查單點尖峰或斷線。
3. **指標切換**：在「指標」中選擇 `P95`、`AVG`、`Timeout%`、`Jitter`。切換後會重新套用到目前的歷史回放或區間統計。
4. **區間與趨勢統計**：點擊上方控制列的 **「區間統計」** 按鈕，即可在彈出的視窗中選取「基準日期」並點選以下三種查詢模式：
   - **單日每時**：顯示所選日期當天從 00:00 到 23:00 共 24 個小時的每小時趨勢。在單日每時模式下，按 `A`/`D`（或左右滑動）可直接快速切換至「前一天 / 後一天」觀看趨勢。
   - **日趨勢**：以基準日期往前推算，顯示過去 N 天（`day_range`）的每日趨勢。
   - **月趨勢**：以基準日期往前推算，顯示過去 N 個月（`month_range`）的每月趨勢。

> [!NOTE]
> `AVG`、`P95`、`Jitter` 會以有效 Ping 樣本計算；`Timeout%` 會以 timeout 筆數佔全部樣本的比例計算。若某小時/某天/某月完全無數據，則該時間點不會出現在圖表上。

## ✨ 核心特色

1. **極簡單一執行檔**：完全無外部相依檔案，只要一個 `pingShow.exe` 即可在任何 Windows 電腦隨處執行。
2. **極致輕量與省電**：採用高效並發技術，系統資源與記憶體消耗極低，適合 24 小時常駐背景執行。
3. **無痛擴充監控對象**：只要在 `target.json` 裡面加入你想測試的 IP，網頁就會自動長出專屬的圖表，不需任何複雜設定。
4. **即時與歷史雙模式**：
   - **LIVE 即時監控**：每秒更新最新連線狀況，捕捉瞬間的延遲與掉包。
   - **歷史回放**：支援調閱過去任意整點時段的詳細歷史曲線與數值。
   - **長跨度趨勢**：提供「日平均」與「月平均」檢視，方便觀察長期（整月或整年）的連線品質波動。
5. **完美支援手機瀏覽**：手機版自動切換為好讀的垂直單欄版面，並支援「手指左右滑動」無縫切換歷史時間。
6. **🖥️ 智慧雙欄排版佈局**：電腦版網頁會根據你監控的 IP 數量，自動套用最飽滿的版面：
   - **1 個 IP**：獨自橫向、縱向拉滿整個網頁。
   - **2 個 IP**：自動呈單直欄、上下堆疊拉滿整個網頁。
   - **3 個及以上 IP**：永遠維持精緻的**「雙欄縱向優先」**排列（例如：5 個 IP 排成 `1 4 / 2 5 / 3`，6 個 IP 排成 `1 4 / 2 5 / 3 6`），最多維持兩欄並自動往下延伸，美感與資訊密度極佳！

## 🚀 簡易使用說明

### 1. 調整連接埠與增刪監控目標 (設定 `target.json`)
當你第一次執行本程式後，根目錄會自動產生一個乾淨的 `target.json` 設定檔。
你可以自由變更網頁服務執行的連接埠（`port`），並在 `targets` 陣列中增減你想監控的名稱 (`name`) 與網址/IP (`ip`)：

```json
{
    "port": 80,
    "targets": [
        {
            "name": "local",
            "ip": "192.168.0.1"
        },
        {
            "name": "Taiwan",
            "ip": "168.95.1.1"
        },
        {
            "name": "Google",
            "ip": "8.8.8.8"
        }
    ]
}
```

---

### 2. 啟動與觀看
1. **以管理員權限啟動**：在 `pingShow.exe` 按右鍵，選擇 **「以系統管理員身份執行」**（因為發送測試網路封包需要 Windows 系統的管理員權限）。
2. **打開網頁**：在瀏覽器中開啟：`http://localhost`，即可看到精美的宮格儀表板。

## 🕹️ 網頁操作與數據解讀指南

### 💡 數據解讀面板 (Stats)
每個圖表上方都會顯示專業的連線品質指標，系統會自動在**「即時模式」**與**「歷史模式」**之間智慧切換數值：

* `min` / `max` / `avg`：該時段內的最快、最慢 與 平均延遲時間 (毫秒)。
* `jtr` (Jitter, 網路抖動率)：數值越低代表網路越穩定。如果抖動率很高，玩遊戲或通話就會感覺時不時瞬移、卡頓。
* `p95` (第 95 百分位數)：代表 95% 的時間延遲都低於這個數字，比「平均值」更能真實反映出「最差的連線底線」。
* `t/o` (Timeout, 逾時)：代表**該時段內斷線/掉包的累積次數**。

> [!NOTE]
> **LIVE 即時模式下**的統計數值會在 **每小時整點（如 14:00、15:00）自動重置歸零**，永遠只呈現「當前這一小時內」的連線狀態。
> **歷史模式下**則會自動分析你所選擇的**「那一整個歷史小時」**的全部數據。

### ⌨️ 快捷鍵與滑動操作 (無縫時空穿梭)
你可以用最直覺的手勢或按鍵，在即時監控與歷史數據之間來回穿梭：

* **往回看歷史**：
  * 電腦按下 **`A`** 鍵、**`左方向鍵 (←)`**，或在手機上**「向右滑動」**：持續往上一個小時切換。若該時段沒有資料，會顯示提示，方便你繼續往前尋找更早的記錄。
* **往前看 / 切回即時**：
  * 電腦按下 **`D`** 鍵、**`右方向鍵 (→)`**，或在手機上**「向左滑動」**：往下一小時切換。當切換到最底的「未來」時，**會全自動、無縫切換回 LIVE 即時監控模式**！
* **智慧切回即時按鈕** 🟢：
  * 在你進入歷史回放或區間總覽模式時，網頁右側會自動浮現綠色的 **「切回即時」** 按鈕，點選即可瞬間切回 LIVE 監控！而在即時監控下，該按鈕會自動隱藏，維持介面極致乾淨。

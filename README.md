## ✨ 核心特色

1. **即時監控**：每秒自動更新各監控目標的 Ping 延遲與連線狀態。
2. **輕量與低耗能**：資源佔用極低，完美適配 Raspberry Pi 或 IoT 設備 24 小時長駐背景執行。
3. **動態擴充監控對象**：透過網頁設定面板或直接編輯 `target.json` 即可新增/刪除 IP，圖表自動對應生成，無需重啟即可動態套用。
4. **即時 / 歷史 / 區間三種模式**：
   - **即時監控 (LIVE)**：每秒更新最新連線延遲與斷線狀態。
   - **歷史回放**：查詢過去任意整點小時的歷史波形曲線，支援「原始數據」/ 「1 分鐘平均」/ 「10 分鐘平均」三種聚合方式。
   - **趨勢檢視**：提供「日平均」與「月平均」長期走勢圖，天數/月份範圍可在設定中調整。
5. **手機與電腦雙版面**：
   - **手機**：自動切換為垂直單欄，支援左右滑動手勢切換歷史時段。
   - **電腦**：根據監控目標數量自動排版（1 個→全螢幕；2 個→上下雙欄；3 個以上→2×N 雙欄縱向排列）。

## 🚀 簡易使用說明

### 1. 設定 `target.json`
第一次執行後，根目錄會自動產生預設的 `target.json`。
你可以直接編輯，或透過網頁的 **「⚙️ 設定」** 按鈕在瀏覽器中修改並儲存：

| 參數 | 說明 | 預設值 |
|---|---|---|
| `port` | 網頁服務連接埠 | `80` |
| `interval` | Ping 間隔秒數 | `1` |
| `ymax` | 圖表 Y 軸最大值 (ms) | `50` |
| `day_range` | 日平均顯示天數 | `7` |
| `month_range` | 月平均顯示月份數 | `3` |
| `targets` | 監控目標列表（name + ip） | — |

```json
{
    "port": 80,
    "interval": 1,
    "ymax": 50,
    "day_range": 7,
    "month_range": 3,
    "targets": [
        { "name": "local",  "ip": "192.168.0.1" },
        { "name": "Taiwan", "ip": "168.95.1.1" },
        { "name": "Google", "ip": "8.8.8.8" }
    ]
}
```

> [!NOTE]
> 修改 `port` 後需重新啟動程式才能生效。其他所有設定（interval、ymax、day_range、month_range、targets 列表）皆可透過網頁設定面板**即時套用，無需重啟**。

---

### 2. 啟動程式

1. **Windows**：在 `pingShow.exe` 按右鍵 → **「以系統管理員身份執行」**（發送 ICMP 封包需要管理員權限）。
2. **Linux / Android (Termux)**：程式自動切換為 UDP Ping 模式，**無需 Root**，直接執行即可。
3. **開啟瀏覽器**：前往 `http://localhost`（若有改 port 則加上 `:port`）。

## 🕹️ 網頁操作與數據解讀指南

### ⚙️ 網頁設定面板
點擊右上角 **「⚙️ 設定」** 按鈕，彈出設定視窗：
* **監控目標管理**：可動態新增、改名、刪除目標。儲存後後端立即啟動或停止對應的 Ping 背景服務，**網頁自動重新整理**，完全無需重啟程式。
* **圖表參數**：可修改 Y 軸上限 (`ymax`)、日平均天數 (`day_range`)、月平均月數 (`month_range`)。
* **連接埠**：修改 `port` 後會提示需重啟，其他設定皆即時生效。
* **乾淨存檔**：儲存時自動過濾運行時統計數值，`target.json` 只保留純粹的設定結構。

---

### 💡 數據解讀面板 (Stats)
每個圖表上方顯示連線品質統計，**即時模式**與**歷史模式**下的數值分別計算：

| 指標 | 說明 |
|---|---|
| `min` / `max` / `avg` | 該時段最快、最慢、平均延遲（毫秒） |
| `jtr` | Jitter（抖動率），數值越低代表連線越穩定 |
| `p95` | 第 95 百分位數延遲，代表 95% 時間低於此值 |
| `t/o` | Timeout 次數（斷線/掉包），圖表以「留白」呈現斷線，而非降至 0 |

> [!NOTE]
> **LIVE 即時模式**下的 Stats 數值會在**每小時整點自動重置**，永遠只顯示當前這一小時的統計。
> **歷史回放模式**則顯示所選整點小時內的全部數據統計。

---

### ⌨️ 快捷鍵與滑動手勢

| 操作 | 電腦 | 手機 |
|---|---|---|
| 查看上一小時（往回） | `A` 鍵 / `←` 方向鍵 | 向右滑動 |
| 查看下一小時（往後） | `D` 鍵 / `→` 方向鍵 | 向左滑動 |
| 切回 LIVE 即時 | 點擊綠色「切回即時」按鈕 | 同左 |

> [!TIP]
> 在 LIVE 模式下第一次按 `A`（右滑），會先停在「**當前小時的歷史靜態檢視**」，再按一下才往前跳上一小時。這讓你可以觀察「這個小時截至目前的歷史統計」，而不是直接跳過。
> 在歷史模式下按 `D`（左滑），當時間超過現在時刻，才會自動切回 LIVE 即時模式。

---

### 📊 歷史數據查詢

1. **小時回放**：在上方控制列選擇「日期」與「時段」，點擊「載入」或按 `A`/`D` 鍵切換。
2. **日平均**：點擊「日平均」按鈕，顯示過去 N 天（`day_range`）每日平均延遲折線圖。
3. **月平均**：點擊「月平均」按鈕，顯示過去 N 個月（`month_range`）每月平均延遲折線圖。

> [!NOTE]
> 日/月平均僅計算有效連線時段（排除 Timeout 筆數），若某天/某月完全無數據，則該時間點不會出現在圖表上。

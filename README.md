## ✨ 核心特色

1. **單一執行檔**：無外部相依檔案，僅需單個執行檔即可運行。
2. **輕量與低耗能**：系統資源與記憶體佔用低，適合長駐背景執行。
3. **動態擴充監控對象**：於 `target.json` 設定 IP 後，網頁會自動生成對應的圖表，不需複雜設定。
4. **即時與歷史雙模式**：
   - **即時監控**：每秒更新最新連線延遲與斷線狀態。
   - **歷史回放**：支援查詢過去整點時段的歷史曲線。
   - **趨勢檢視**：提供「日平均」與「月平均」檢視，便於觀察長期連線品質波動。
5. **支援行動裝置瀏覽**：手機版自動切換為垂直單欄版面，並支援左右滑動切換歷史時間。
6. **電腦版雙欄佈局**：電腦版網頁會根據監控的項目數量調整版面：
   - **1 個監控目標**：單一圖表填滿網頁。
   - **2 個監控目標**：雙圖表採上下堆疊填滿網頁。
   - **3 個及以上監控目標**：採用雙欄縱向排列（例如：5 個 IP 排成 `1 4 / 2 5 / 3`，6 個 IP 排成 `1 4 / 2 5 / 3 6`），最多維持兩欄並自動向下延伸。

## 🚀 簡易使用說明

### 1. 調整連接埠與增刪監控目標 (設定 `target.json`)
當你第一次執行本程式後，根目錄會自動產生一個預設的 `target.json` 設定檔。
你可以自由變更網頁服務執行的連接埠（`port`），並在 `targets` 陣列中增減你想監控的名稱 (`name`) 與網址/IP (`ip`)：

```json
{
    "port": 80,
    "targets": [
        {
            "name": "local",
            "ip": "192.168.0.1"
        },
        {
            "name": "Taiwan",
            "ip": "168.95.1.1"
        },
        {
            "name": "Google",
            "ip": "8.8.8.8"
        }
    ]
}
```

---

### 2. 啟動與觀看
1. **以管理員權限啟動**：在 `pingShow.exe` 按右鍵，選擇 **「以系統管理員身份執行」**（因為發送測試網路封包需要 Windows 系統的管理員權限）。
2. **打開網頁**：在瀏覽器中開啟：`http://localhost`，即可看到監控儀表板。

## 🕹️ 網頁操作與數據解讀指南

### 💡 數據解讀面板 (Stats)
每個圖表上方都會顯示連線品質統計指標，系統會自動在**「即時模式」**與**「歷史模式」**之間切換數值：

* `min` / `max` / `avg`：該時段內的最快、最慢與平均延遲時間 (毫秒)。
* `jtr` (Jitter, 網路抖動率)：數值越低代表網路越穩定。若抖動率高，代表延遲時間不穩定。
* `p95` (第 95 百分位數)：代表 95% 的時間延遲都低於此數值，反映大部分網路延遲的上限水準。
* `t/o` (Timeout, 逾時)：代表**該時段內斷線/掉包的累積次數**。

> [!NOTE]
> **LIVE 即時模式下**的統計數值會在 **每小時整點（如 14:00、15:00）自動重置歸零**，永遠只呈現「當前這一小時內」的連線狀態。
> **歷史模式下**則會自動分析你所選擇的**「那一整個歷史小時」**的全部數據。

---

### ⌨️ 快捷鍵與滑動操作
可以透過鍵盤快捷鍵或手勢，在即時監控與歷史數據之間切換：

* **往回看歷史**：
  * 電腦按下 **`A`** 鍵、**`左方向鍵 (←)`**，或在手機上**「向右滑動」**：往上一個小時切換。
* **往前看 / 切回即時**：
  * 電腦按下 **`D`** 鍵、**`右方向鍵 (→)`**，或在手機上**「向左滑動」**：往下一小時切換。當切換到最新時段時，會自動切換回 LIVE 即時監控模式。
* **切回即時按鈕** 🟢：
  * 在進入歷史回放或區間總覽模式時，網頁右側會顯示綠色的 **「切回即時」** 按鈕，點選即可切回即時監控。在即時監控模式下，該按鈕會自動隱藏。
